# Lo que no se construye en esta etapa

Funcionalidades posteriores (solo después de tener retención o ingresos reales, no
antes): aplicación móvil, audio personalizado, brief conversacional, preguntas sobre
una historia, mapas de acontecimientos, gráficos de cobertura, API pública,
integraciones empresariales, predicción de temas emergentes, análisis multilingüe,
alertas por anomalías, resúmenes para radio, etiquetas de sesgo/enfoque editorial
(requiere metodología transparente y probablemente asesoría legal), canal seguro para
fuentes periodísticas (requiere equipo legal y editorial dedicado).

## Explícitamente prohibido en esta etapa

- WikiLeaks pagado.
- Ranking de personas acusadas.
- Sistema de comentarios públicos.
- Red social interna, likes y seguidores.
- Marketplace de noticias.
- Token o criptomoneda.
- Modelo de IA propio (seguir usando Groq/OpenAI vía `src/llm/`).
- Chatbot genérico.
- Aplicación iOS/Android.
- Soporte para veinte países simultáneos.
- Sistema complejo de gamificación.
- Panel ambiental basado en estimaciones difíciles de defender.
- Bloqueos de captura de pantalla.
- Blockchain para "verificar noticias".
- Cualquier función llamativa sin usuarios que la hayan pedido.

**Ninguna de estas aumenta por sí sola la probabilidad de entrar a YC.** Si aparece la
tentación de construir algo de esta lista durante las Fases 0–6, es una señal de que se
está evitando el trabajo más difícil (conseguir usuarios y clientes reales), no de que
el producto lo necesita.
